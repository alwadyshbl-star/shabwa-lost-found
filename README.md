# أثر | منصة المفقودات والموجودات

منصة ويب عربية تعمل باتجاه **RTL** لتنظيم الإبلاغ عن المفقودات والموجودات والبحث عنها ومطابقتها. يبدأ الحل من **مدينة عتق** مع قابلية التوسع إلى **محافظة شبوة** ثم اليمن، ويهدف إلى تحويل البلاغات المتفرقة في وسائل التواصل إلى مسار منظم وواضح يساعد من فقد غرضًا ومن عثر عليه.

> **فكرة المنصة:** كل أثر يستحق أن يعود إلى صاحبه. لا تعتبر المطابقة إثباتًا للملكية؛ بل تقدم احتمالًا منظمًا يساعد الأطراف على مراجعة التفاصيل والتواصل والتحقق بصورة مسؤولة.

## المزايا الرئيسة

| المجال | ما يقدمه المشروع |
|---|---|
| الحسابات | إنشاء حساب محلي بالبريد وكلمة المرور، وتسجيل الدخول والخروج، والدخول كزائر للتصفح العام. |
| البلاغات | إضافة بلاغ مفقود أو موجود لشخص أو حيوان أو غرض، مع الاسم والوصف والموقع والتاريخ وبيانات التواصل. |
| البحث | استكشاف البلاغات العامة والبحث والتصفية حسب البيانات المتاحة. |
| المطابقة | مقارنة ذكية بين بلاغات المفقودات والموجودات وإظهار نسبة التشابه. |
| الإشعارات | إشعارات داخل التطبيق للطرفين عند وجود تطابق محتمل، مع عداد للرسائل غير المقروءة. |
| لوحة المستخدم | إدارة البلاغات الشخصية، تعديلها، وتعليمها بأنها تم استرجاعها. |
| الإعدادات | عرض الاسم والبريد، تغيير كلمة المرور، وحذف الحساب بتأكيد صريح. |
| الإدارة | مركز للمشرف لإدارة المستخدمين والبلاغات والإحصاءات والصلاحيات. |
| اللغة والتجربة | واجهات عربية كاملة بتصميم RTL واستجابة للجوال وسطح المكتب ورسائل أخطاء مفهومة. |

## آلية المطابقة

تعمل المطابقة في الخادم باستخدام **TypeScript** وخوارزمية **Jaccard Similarity**. يطبع النظام النص العربي أولًا بتوحيد أشكال الحروف الشائعة وإزالة التشكيل والكلمات العامة، ثم يقارن البلاغات المتعاكسة فقط: مفقود مقابل موجود، ومن نوع الكيان نفسه.

تُحسب النتيجة من مزيج موزون يشمل نوع الكيان والاسم والوصف والموقع وقرب التاريخ. إذا وصلت النتيجة إلى **50%** أو أكثر، تسجل المنصة تطابقًا محتملًا وتنشئ إشعارًا للطرفين. عند تعديل البلاغ أو زوال التشابه، تُحدَّث المطابقات والإشعارات المرتبطة بها تلقائيًا.

## متطلبات التشغيل المحلي

يحتاج المشروع إلى **Node.js 22 أو أحدث**، و**pnpm**، وقاعدة **MySQL 8** أو TiDB. تأكد من عدم رفع ملف البيئة `.env` إلى GitHub لأنه يحتوي على أسرار الاتصال.

### 1. استنساخ المشروع وتثبيت الحزم

```bash
git clone <REPOSITORY_URL>
cd shabwa-lost-found
corepack enable
pnpm install
```

### 2. إنشاء قاعدة البيانات

بعد تشغيل MySQL محليًا، أنشئ قاعدة بيانات باسم `athar`:

```bash
mysql -u root -p -e "CREATE DATABASE athar CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
```

### 3. إنشاء ملف البيئة

أنشئ ملفًا باسم `.env` في جذر المشروع وضع فيه القيم التالية، مع استبدال القيم النموذجية بقيمك الفعلية:

```env
DATABASE_URL="mysql://root:YOUR_MYSQL_PASSWORD@127.0.0.1:3306/athar"
JWT_SECRET="ضع_هنا_مفتاحًا_عشوائيًا_طويلًا_وسريًا"
ADMIN_SETUP_CODE="رمز_سري_خاص_بتفعيل_المشرف"
```

يمكن إنشاء مفتاح عشوائي قوي للأسرار باستخدام:

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

### 4. تجهيز الجداول وتشغيل الموقع

```bash
pnpm db:push
pnpm dev
```

ثم افتح المتصفح على الرابط التالي:

```text
http://localhost:3000
```

## النشر والإنتاج

يحتاج المشروع إلى استضافة تدعم **Node.js** وقاعدة **MySQL/TiDB**؛ لأنه يتضمن خادمًا ومصادقة وقاعدة بيانات، وليس موقعًا ثابتًا فقط. عند النشر، أضف متغيرات البيئة من لوحة الاستضافة، ولا تضعها في الشفرة أو في GitHub.

تشمل المتغيرات الأساسية: `DATABASE_URL` و`JWT_SECRET` و`ADMIN_SETUP_CODE`. تأكد من استخدام HTTPS في الإنتاج لحماية جلسات المستخدمين وبياناتهم.
