# مراجعة رحلة المستخدم — منصة أثر

| المرحلة | نقطة الاحتكاك التي رُوجعت | التحسين المنفذ | الأثر المتوقع |
| --- | --- | --- | --- |
| الدخول الأول | عدم وضوح الفرق بين الحساب والزائر | شاشة اختيار أولي، وحفظ وضع الزائر، وشريط يوضح حدوده | قرار دخول أسرع وتوقعات واضحة |
| الاستكشاف والبحث | غياب معرفة المرحلة الحالية وضعف التمييز البصري للبطاقات دون صورة | مؤشر رحلة ثابت، وبطاقات ذات رموز وخلفيات مرتبطة بنوع الحالة | وصول أسهل إلى البحث وفهم أسرع للنتائج |
| إنشاء البلاغ | الحاجة إلى تذكير مختصر بما يفيد المطابقة وما يجب عدم مشاركته | دليل قبل النموذج مع 3 تذكيرات عملية، إلى جانب تحذيرات النموذج | جودة بيانات أفضل ومخاطر خصوصية أقل |
| التطابقات | احتمال اعتبار درجة التشابه إثباتًا للملكية | ترتيب واضح للبطاقات وملاحظة تحقق قبل التواصل | تواصل أكثر أمانًا واسترجاع مسؤول |
| لوحة المستخدم | غياب النظرة الإجمالية والحاجة إلى تحديد الخطوة التالية | ملخص لبلاغات المستخدم وحالات المتابعة والاسترجاع | متابعة أسرع للإجراءات المتكررة |
| الإشعارات | صعوبة معرفة ما يحتاج تدخلاً عاجلاً | ملخص بعدد التحديثات غير المقروءة وإجراء «مراجعة البلاغ» | تقليل فقدان التحديثات المهمة |
| الإشراف | غياب أولويات واضحة لطابور المراجعة | ملخص المنشور وقيد المراجعة وتعليمات بدء العمل | قرار إشرافي أوضح وأسرع |

## معايير التحقق

تمت مراجعة مسارات الدخول الأول، الاستكشاف، البحث، إضافة البلاغ، تفاصيل البلاغ، لوحة المستخدم، الإشعارات، ولوحة الإشراف على سطح المكتب والجوال. تُحفظ قواعد الوصول الحالية كما هي: التصفح العام متاح للزائر، بينما تتطلب إضافة البلاغات وإدارة التطابقات حسابًا مسجلاً.
